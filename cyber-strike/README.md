# Cyber Strike

Mobile-friendly browser arcade shooter prototype.

## Run
Open `cyber-strike/index.html` from a web server (HTTPS is recommended for PWA features).

## Online play
The prototype uses PeerJS for a lightweight peer-to-peer room connection. Create a room and share the room code with another player.

## PWA
The project includes a web manifest and service worker and is structured for PWABuilder packaging.
